
# Stock-Manager

O Stock Manager é um futuro software que tem como premissa, controlar estoque

com as principais funções sendo controle e gerenciamento de estoque, entrada e saida de itens/produtos




## Features

com as principais funções sendo:

- Controle e gerenciamento de estoque
- Entrada e saida de produtos/itens
